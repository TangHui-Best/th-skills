# 技术架构图：图标素材与视觉表达参考

制作技术架构、系统集成、调用流程类页面时使用本参考。复用对象、配色和关系表达，按当前任务的机制与信息量组织版式；沿用用户模板和明确指定的视觉要求。

> **素材分级：通用视觉参考。** 用户已确认本目录图片不含敏感业务信息；本次可见内容审视未发现可识别的组织、个人或平台标记。整页示例仍只用于视觉搭配与关系表达，不将其标签或拓扑当作新项目事实。未来替换为其他来源材料时，重新执行素材分级与标记检查。

## 1. 先查看参考，再选择素材

- 整页示例：`../assets/technical-architecture/reference-slide.png`，用于本地或获授权的视觉参考。
- 查看整页，理解对象大小、图标搭配、主调用链、控制标签与观测分支的关系。
- 按下表选用透明背景PNG。它们基于用户确认的通用示例整理，保留主要视觉特征，属于栅格素材；要求逐像素一致时，应先确认原图是否允许用于当前交付与处理环境。
- 将图标文件嵌入最终PPT或其他交付文件，避免依赖技能目录中的外部图片链接。

| 对象 | 素材路径 | 使用约定 |
|---|---|---|
| 用户 / 客户端 | `../assets/technical-architecture/client.png` | 表示人机交互入口；保留具体角色与协议标签 |
| Agent | `../assets/technical-architecture/agent.png` | 调用方与业务方共用图标，通过标签区分职责 |
| MCP工具 / 工具集 | `../assets/technical-architecture/mcp-tools.png` | 用工具箱表达工具集合；按实际对象命名，不与Agent混用 |
| 应用服务 | `../assets/technical-architecture/application-service.png` | 用服务器表达应用服务；表示数据库等新对象时补充相应素材与标签 |
| 网关 / 控制组件 | 使用原生PPT深蓝圆角矩形与白色文字 | 用名称区分Agent网关、MCP网关等组件，保持可编辑 |
| 控制能力 | 使用原生PPT浅蓝标签与深色文字 | 放在实际生效的组件附近，按需连接或注明范围 |

## 2. 保持一致的图标风格

- 采用等距视角、轻立体插画，蓝青为主色，白色为辅助，少量黄色突出工具与细节。
- 保持图标朝向、材质、细节密度与视觉重量相近。已有图标直接复用，避免跨页反复生成同一对象造成漂移。
- 新增模型、数据库、消息队列等素材时，选用已获授权的通用图标作为视觉参考；对于客户、内部或受限副本，只有在脱敏后获准外发时才可交给图像工具，保留新对象本身的可辨识特征。
- 按可见主体统一大小，考虑透明留白差异；保持宽高比，避免拉伸或过度放大。
- 将图标放在白色或浅色背景上检查边缘与光晕；确保适合实际投屏尺寸。保留必要材质感，避免增加背景发光、纹理或装饰。

## 3. 用关系组织架构

- 在页内明确主调用方向；适合时横向展开，分支与汇聚按真实调用关系绘制。复杂拓扑可改为分层或纵向布局。
- 将对象名称放在图标附近；将协议标签放在相关入口或连线上，避免协议标签与业务角色混淆。
- 用浅蓝标签说明权限、鉴权等控制能力，关联实际执行组件；不要把配置对象自动等同于执行位置。例如管理面能配置MCP工具权限，不足以证明检查一定由MCP网关执行。
- 区分业务调用、控制关联和遥测采集的线型，并通过标签或图例解释。优先用实线箭头表示调用、虚线表示观测关联；箭头方向按真实语义确定。
- 让日志线指向采集或查看目标。仅表达覆盖关系时可用无箭头虚线，避免误画成日志向业务组件发起调用。
- 在图中讲清机制，必要时在下方补少量能力说明；根据内容决定是否需要三列卡片、底部业务条或对比区域。

## 4. 单独确认事实边界

- 从当前材料建立对象、协议、调用路径、控制执行点、日志覆盖范围与建设状态清单，再画连线。
- 整页示例中的Agent网关、MCP网关、工具、应用之间的关系，只是该示例的结构，不能作为所有项目的固定拓扑。
- 示例中的日志尚未覆盖MCP网关与MCP工具。用于新项目时重新确认覆盖范围；没有依据时不连线，不写全链路已覆盖，也不将调用追踪等同于安全审计。
- 将已完成能力、试点联调、预计接入规模分别表述。示例可能包含项目、阶段或规模等内部业务语境；它们不属于可复用事实，也不得带入新稿或外部提示词。
- 使用红色标题或蓝色网关是示例的搭配方式；按用户模板选择颜色，不将颜色变化自动解释为风险或完成状态。

## 5. 生成与重建要求

- 仅在用户确认素材可用于当前外部工具与交付范围后，才向外部图像工具提供参考图或图标；否则在本地查看参考，使用文字描述或重新绘制的通用图形。整页参考仅用于搭配与表达，图标用于保持对象视觉一致；仅提供文件路径文字不足以让图像工具看到参考图。
- 在提示中分别写明保留对象外观、按当前内容重组拓扑、准确文字及禁止增加的能力；不得把参考页中的标签、拓扑、权限边界或日志覆盖范围伪装成新项目事实。
- 重建可编辑PPT时嵌入独立图标，使用原生文字、网关面板、控制标签和连接线；不要把整页截图作为可编辑内容。
- 遵循SKILL.md的验收流程，检查对象映射、同类图标一致性、连线方向、文字可读性、覆盖范围及建设状态。
